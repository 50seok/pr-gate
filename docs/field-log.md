형식: `PR #N  머신 판정 → 정탐/오탐/누락. 근거`

## 누적 요약 (2026-09-12 기준)

- 정탐 18 / 오탐 0 / 누락 0 (관찰된 범위 내)
- P1은 한 번도 안 나옴 — 1인 개인 프로젝트라 트랜잭션·동시성·인증 같은 P1급 영역이 원래 적다
- **가장 값진 패턴이 두 번 반복됐다**: PR #4 R2(`<` 버그)와 PR #8 R2(exclude_type 리셋) 둘 다 "내가 직전 라운드에서 P2를 고치다가 새 버그를 만들었는데, 머신이 바로 다음 라운드에서 그걸 잡았다"는 동일한 구조다. 1회성 우연이 아니라 **사람이 자기 코드(그리고 자기 코드의 수정)를 자기가 검증하는 데는 구조적 사각지대가 있고, pr-gate가 그 사각지대를 반복적으로 메운다**는 재현 가능한 신호로 봐야 한다
- **관찰 범위 밖 사각지대 1건(2026-09-11)**: PR 절차를 안 거친 커밋은 pr-gate가 볼 기회 자체가 없다 — "정탐률"이 100%에 가까워도 그건 "PR로 온 것 중" 얘기다
